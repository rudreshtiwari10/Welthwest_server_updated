=================================================================================
    IMPORTANT STEPS BEFORE STARTING IMPLEMENTATION
=================================================================================

1. GET CASHFREE CREDENTIALS:
   - Go to https://www.cashfree.com/ and create a merchant account
   - Get your Sandbox App ID and Secret Key from the dashboard
   - Configure webhooks and get the Webhook Secret
   - Replace the placeholder values above

2. VERIFY REDIS IS RUNNING:
   Run: redis-cli ping
   Expected output: PONG

3. VERIFY MONGODB IS RUNNING:
   Check your MONGODB_URI is accessible

4. DECIDE ON INITIAL PAYMENT GATEWAY STATE:
   - For development/testing: IS_PAYMENT_GATEWAY_ENABLED=false
   - For payment testing: IS_PAYMENT_GATEWAY_ENABLED=true with sandbox
   - For production: IS_PAYMENT_GATEWAY_ENABLED=true with production

=================================================================================
    YOU CAN CUSTOMIZE THESE VALUES
=================================================================================

Feel free to adjust:
- Plan prices (PLAN_*_WEEKLY, PLAN_*_MONTHLY, PLAN_*_ANNUAL)
- Per-feature limits (PLAN_*__MARKET_REGIME, etc.)
- Anonymous limits (ANON_*_LIMIT)
- Server timezone (SERVER_TIMEZONE)

The implementation will automatically read these values, so no code changes
are needed when you adjust limits or prices!
